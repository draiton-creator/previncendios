# Módulo de Componentes de Interfaz (`src/components`)

## Descripción
Colección modular de componentes UI organizados por área funcional:

- `/common/`: Header, Sidebar, Badge, StatCard, RoleSelectorModal, Modal, Toast.
- `/map/`: EmergencyMap (Leaflet GPS en tiempo real), LayerControl, MapFilter.
- `/incidents/`: IncidentList, IncidentDetailModal, NewIncidentModal.
- `/alerts/`: AlertCenter, CreateAlertModal, AlertBanner.
- `/resources/`: ResourceList, ResourceRequestModal.
- `/volunteers/`: VolunteerDirectory.
- `/communications/`: AnnouncementsList, CreateBandoModal.
- `/documents/`: DocumentLibrary.
- `/audit/`: AuditLogsList.
