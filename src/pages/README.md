# Módulo de Vistas y Páginas (`src/pages`)

## Descripción
Contiene los dashboards adaptados por rol y las páginas principales de la aplicación:

- `/dashboards/`:
  - `SuperAdminDashboard.tsx`: Panel nacional con visión global de España, satélites FIRMS y UME.
  - `MunicipalDashboard.tsx`: CECOPAL local, previsión meteorológica AEMET y retenes municipaales.
  - `CitizenDashboard.tsx`: Perfil para vecinos y voluntarios con estado de ubicación GPS.
  - `GuestDashboard.tsx`: Vista pública libre de registro con mapa de incendios abierto.
- `/map/`: `FullMapPage.tsx`
- `/incidents/`: `IncidentsPage.tsx`
- `/alerts/`: `AlertsPage.tsx`
- `/resources/`: `ResourcesPage.tsx`
- `/volunteers/`: `VolunteersPage.tsx`
- `/communications/`: `CommunicationsPage.tsx`
- `/documents/`: `DocumentsPage.tsx`
- `/audit/`: `AuditPage.tsx`
