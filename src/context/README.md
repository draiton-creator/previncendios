# Módulo de Contextos React (`src/context`)

## Descripción
Manejo centralizado del estado global de la aplicación mediante React Context API.

## Contextos
- `AuthContext.tsx`: Gestión del perfil del usuario, roles de demostración, autenticación y permisos de geolocalización.
- `ThemeContext.tsx`: Control del modo claro / oscuro.
- `EmergencyContext.tsx`: Estado operativo en tiempo real de incidencias, alertas, recursos, satélites, bandos, auditoría y capas del mapa.
